# 도윤 ♥ 서연 모바일 청첩장

왁스로 봉인된 봉투가 열리고, 빛 속에서 한옥 대문을 지나는 신랑 신부로 이어지는 시네마틱 모바일 청첩장입니다. 인물과 예식장, 계좌는 모두 가상입니다.

- **스틸·사진**: GPT Image 2.5 Flare (Atlas Cloud)
- **영상**: Seedance 2.0 Mini Image-to-Video — 앞 스틸을 첫 프레임, 다음 스틸을 마지막 프레임으로 지정해 클립끼리 끊김 없이 이어짐
- **재생**: 클립을 WebP 프레임으로 변환해 스크롤 위치에 맞춰 캔버스에 표시. 봉투를 누르면 스크롤이 자동으로 이어져 영상이 재생됨
- **포맷**: 휴대폰으로 보는 청첩장이라 세로(9:16)만 만들고, 넓은 화면에서는 가운데에 휴대폰 너비로 표시

## 인터랙션

| 섹션 | 동작 |
|---|---|
| 날짜 | 금박 카드를 긁으면 날짜가 드러남 · 달력 · 실시간 D-day |
| 갤러리 | 옆으로 넘기는 사진 |
| 오시는 길 | 주소 복사 · 네이버 지도/카카오맵/구글 지도 열기 |
| 마음 전하실 곳 | 계좌 펼치기 · 복사 (예시 계좌) |
| 참석 의사 | 응답 요약 표시 (서버가 없어 실제 전송은 하지 않음) |

## 준비와 생성

```bash
npm install
cp .env.example .env             # ATLASCLOUD_API_KEY 입력
npm run generate                 # 실행 계획과 예상 비용만 출력
npm run generate -- --yes        # 실제 생성 (스틸 → 클립 → 프레임)
```

ffmpeg가 PATH에 있어야 합니다.

## 구성 변경

| 파일 | 수정 내용 |
|---|---|
| `story.config.mjs` | 화풍(`style`), 스틸(`stills`)과 그 사이 움직임(`clips`), 사진(`extras`) |
| `index.html` | 이름·날짜·장소·계좌 문구, 예식 시각(`data-wedding`, 시차 포함 ISO 형식) |

## 구조

| 파일 | 역할 |
|---|---|
| `src/main.js` | 오프닝 영상 재생, 챕터 문구 전환, 섹션 연결 |
| `src/film/` | 캔버스 렌더링, 클립별 프레임 로딩 |
| `src/invite/` | 긁는 카드, 달력, 카운트다운, 복사, 참석 의사 |
| `scripts/generate.mjs` | Atlas Cloud 생성 파이프라인 |
